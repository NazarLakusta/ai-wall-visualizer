# Підготовка до зустрічі: Epicentr, відділ фарби

**Мета зустрічі:** не «продати всю мережу завтра», а **домовитись про пілот** (1 магазин / 1 відділ) + зафіксувати інтерес до масштабування.

**Твоя позиція:** готове рішення для пілоту **зараз** + чіткий план **окремого сервісу під Epicentr** (бот, магазини, web).

---

## 1. Пітч на 2 хвилини (вивчити напамʼять)

> «Ми робимо сервіс, де покупець **фотографує свою кімнату** і за 30 секунд бачить **ваш колір фарби або декоративку** на своїх стінах — з **розрахунком банок і ціни** за вашим прайсом.  
> Натискає «Надіслати консультанту» — заявка з телефоном, площею, кольором і сумою потрапляє **менеджерам у Telegram**.  
> Для Epicentr можемо запустити **пілот у вашому магазині за 2–3 тижні**: QR біля палітри, каталог під бренди на полиці.  
> Якщо пілот заходить — **окремий контур під мережу**: свій бот, вибір міста/магазину, заявки по точках, згодом — **вбудовування на epicentr.ua**.»

**Не кажи на старті:** Docker, AI, SegFormer, VPS, «ми замінимо ваш IT».

---

## 2. Що показати на телефоні (демо 5–7 хв)

Підготуй **до зустрічі**:

- [ ] Бот / mini-app відкритий, **dekor-showroom** або тестовий проєкт
- [ ] Завантажене фото кімнати (або «тестова кімната»)
- [ ] Перемикання **фарба** → бренд KROINZ → колір RAL → **ціна змінюється**
- [ ] Режим **декор** → матеріал → відтінок → текстура
- [ ] Площа 20 м² → **розрахунок банок**
- [ ] Форма заявки (можна не відправляти реальний лід)
- [ ] Скрін **адмінки**: заявки, каталог (якщо є доступ з телефону / планшет)

**Фраза під час демо:**  
«Ось так клієнт бачить **свою** стіну, не зразок з вітрини. Консультант отримує вже готовий підбір — менше часу на “а який RAL?”.»


## 6. Умови співпраці (що озвучити)

### Пілот (рекомендований старт)

1. **Договір / рахунок** на setup + 1–3 місяці підписки (ФОП/ТОВ — твоя сторона).
2. **З їхнього боку:**
   - контактна особа (керівник відділу + 1 консультант);
   - Telegram-група для заявок;
   - прайс / список брендів на полиці (Excel або PDF);
   - дозвіл на QR у залі (керуючий магазину — якщо треба);
   - 2 тижні «живого» тесту з консультантами.
3. **З твого боку:**
   - бот, каталог, адмінка, підтримка;
   - звіт по метриках;
   - не передаємо дані іншим клієнтам (ізоляція; для Epicentr — **окремий сервер** на етапі 2).
4. **IP:** ліцензія на використання платформи; код залишається у тебе, якщо не домовитесь інакше (на пілоті — **не віддавай код**).
5. **Після пілоту:** рішення — продовжити / масштабувати / зупинити. Без зобовʼязання на рік.

### Що попросити підписати після «так»

- [ ] Усна домовленість + **рахунок на setup**
- [ ] Список брендів/SKU для каталогу
- [ ] Chat ID групи заявок
- [ ] Дата старту QR у залі

## 7. Ключові питання — відповіді

### Про продукт

**«Що це технічно?»**  
> Telegram-бот і веб-форма (пізніше). Клієнт без установки додатків. Для пілоту — Telegram; для сайту — окремий етап.

**«Чи точний колір?»**  
> Це **орієнтир для вибору**, не заміна зразка на стіні. Мета — звузити вибір з 2000 відтінків до 2–3 перед покупкою.

**«Скільки позицій у каталозі?»**  
> Пілот: **150–300 хітів**. Повний асортимент Epicentr — етап з 1С і пошуком.

**«Telegram — наші клієнти не всі там»**  
> На пілоті консультант може **сам показати** на планшеті. Далі — web на сайті.

**«Що з персональними даними?»**  
> Фото і телефон — для заявки консультанту. Зберігання обмежене (дні). Окремий сервер для Epicentr — дані не змішуються з іншими клієнтами. За запитом — доповнення до договору.

### Про організацію

**«Нам треба на всю мережу»**  
> Логічно. Пропоную **пілот 1 магазин → цифри → план rollout**. Так роблять великі мережі — без ризику на 60 точок одразу.

**«IT зробить самі»**  
> Можуть. Наш плюс — **готово за 2–3 тижні** і досвід саме **фарби** (бази, банки, декор). Можемо **паралельний пілот**, поки IT оцінює. Або ліцензія ядра після пілоту.

**«Як ліди потрапляють у наш магазин?»**  
> Зараз — у **вашу Telegram-групу**. У мережі — клієнт обирає **місто/магазин** → заявка тільки туди.

**«Різні ціни в різних містах?»**  
> Так, **ціна per магазин** в системі можлива. На пілоті — ціни вашого гіперу.

### Про гроші

**«Скільки коштує?»**  
> Пілот: **25–35 тис. ₴ setup** + **12–18 тис. ₴/міс**. Повна мережа — після пілоту, від **80 тис. ₴** розробка + щомісячна підтримка.

**«Чому не безкоштовно?»**  
> Setup — каталог під ваш прайс, бот, QR, навчання. Безкоштовно можемо **демо сьогодні**; запуск у залі — платний пілот.

**«Хто власник даних?»**  
> **Epicentr / магазин.** Ми — оператор платформи за договором.

### Про конкурентів

**«У Dulux / інших є додатки»**  
> У вас — **ваш каталог, ваші ціни, заявка вашому консультанту в Epicentr**, не на сторонній сайт.
